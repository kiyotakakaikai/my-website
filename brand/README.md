# 株式会社上田 ブランドロゴ

2026年10月採用（同月25日に改訂）。漢字「上」を縦棒・土台・赤い横線の3つの部品に分けたマークと、ロゴ専用に描いた英字「UEDA」の組み合わせ。

## 色

| 用途 | 色 | HEX |
|---|---|---|
| メイン（マーク・英字） | 黒 | `#111111` |
| 差し色（マークの赤い横線のみ） | 赤 | `#D7261E` |
| ブランドの線（車両の横線・ホームページのヘッダー下の線） | 紺 | `#1F3A5F` |
| 反転時のメイン | 白 | `#FFFFFF` |

- 赤はマークの横線1か所だけに使う。文字やマーク全体を赤にしない。
- 車両・作業着に赤い横線は入れない（白い車体＋赤い線は救急車に見えるため）。車両の横線は紺を使う。
- 印刷・刺繍・看板の発注時は、画面の色ではなく印刷所の色見本（DIC・PANTONE等の色番号）で実物を確認して指定する。

## 寸法のルール（マークの高さを100とした時）

| 部分 | 値 |
|---|---|
| 線の太さ（縦棒・土台・赤い横線・英字すべて） | 24 |
| 縦棒と土台、縦棒と赤い横線の隙間 | 20 |
| マークの幅 | 108 |
| 英字1文字の幅 / 文字の間隔 | 80 / 40 |
| マークと英字の間隔 | 48 |

## フォント

- 英字「UEDA」はロゴ専用に描いた図形。フォントではないので、インストールは不要。
- 「株式会社上田」（jp版のみ）は Noto Sans CJK JP Bold を図形化済み。Noto Sans CJK は SIL Open Font License で、商用利用可。

## ファイル

| 場所 | 内容 | 使う場面 |
|---|---|---|
| `brand/print/ueda-logo-horizontal-color.*` | 横組み（マーク＋UEDA） | 看板・車両・書類（白い背景） |
| `brand/print/ueda-logo-horizontal-white.*` | 同・白抜き | 作業着・黒い看板（濃い背景） |
| `brand/print/ueda-logo-horizontal-jp-*.*` | 横組み＋「株式会社上田」 | 名刺・見積書・会社案内など正式名が必要な場面 |
| `brand/print/ueda-logo-vertical-*.*` | 縦組み | 看板・車両の後ろ・パンフレットの表紙 |
| `brand/print/ueda-mark-*.*` | マーク単体 | SNSアイコン・名刺の裏・ステッカー |
| `images/brand/logo-header-*.*` | 横組み（余白なし） | ホームページのヘッダー・フッター |
| `/favicon.svg`・`/favicon.ico` | ファビコン（16px用に形を調整済み） | ブラウザのタブ・検索結果 |
| `/apple-touch-icon.png`・`/icon-*.png`・`/site.webmanifest` | ホーム画面アイコン | iPhone・Android |
| `brand/mockups/` | 名刺・作業着・車両・サイトへの当てはめ確認画像 | 社内確認・業者への説明 |

- `.svg` は拡大しても劣化しない。印刷所・刺繍業者・看板業者にはSVGを渡す。
- `.png` は背景透過。Word・PowerPoint・SNSに貼る用。

## 使い方のルール

- ロゴの周りには、マークの線の太さ（24）の2倍以上の余白を空ける。
- 縦横比を変えない・傾けない・影や枠を付けない・部品の隙間を詰めない。
- 背景が明るい時は color、暗い時は white を使う。
- 英字の高さが3mm未満になる場面ではマーク単体を使う。16px程度の極小サイズでは `favicon.svg` の形を使う（隙間が潰れないよう調整済み）。
- 商標登録を検討する場合は、事前に特許庁 J-PlatPat で類似の図形商標を確認する。
